Add a Browser source in OBS, then paste this URL.

  1. In OBS, select Sources → + → Browser and name it “Skincast”.
  2. Paste the overlay URL. Set width and height to 800 × 800. Leave “Local file” unchecked.
  3. Keep this studio tab open with the microphone enabled. Position and resize the Browser source in your scene.
  4. Choose Transparent above for a clean cutout. Changes here appear in OBS automatically.

First launch on macOS needs Xcode Command Line Tools to compile the cursor helper. Windows uses PowerShell. Linux X11 needs xdotool and Python 3. A game that locks the cursor to the center will center the avatar’s gaze.
